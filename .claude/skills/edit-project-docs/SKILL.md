# 文書ルールに沿って編集

作業場所がRaiseTech_TaskManagerであることを確認し、リポジトリルートを特定する。編集や実行の前に、そのルートの `CLAUDE.md` と `運用/文書運用ルール.md` を必ず読んで従う。ルールを読めない場合は推測で進めず、場所を調べ、見つからなければ理由を報告する。

対象文書と実装を照合し、文書の役割に合う場所へ情報を置く。実行結果・Issue別の履歴を恒久文書へ追加しない。利用上の制限は残し、テスト未確認を成功扱いしない。変更後にリンク・図・コードブロック・差分を確認し、実施結果を作業報告へまとめる。

既存のIssue・ブランチと未コミット変更を確認し、worktreeは使わない。コミット・push・PRは明示的な依頼がある場合のみ行う。
